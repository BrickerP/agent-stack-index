### Algolia
Algolia is a hosted search API with typo tolerance, faceting, synonyms, analytics and AI-based ranking, built for low-latency results on large catalogs. It is fully managed, with no servers to run. JavaScript client: `npm i algoliasearch`; prebuilt UI widgets via InstantSearch. Free tier with usage-based paid plans. Indexing and querying go through a REST API.
